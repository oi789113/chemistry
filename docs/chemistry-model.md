# 化学与可视化模型

## 适用范围

ChemLab 是初高中教学用的、物质数量守恒的**规则式虚拟实验系统**，不是通用化学预测器、实测动力学软件或真实操作安全指南。60 种物质中包含试剂、产物、催化剂和指示剂；只实现下表的 14 条化学反应规则。未注册的组合会提示暂未支持，不推断新产物。复杂混合物可能有未建模的竞争反应，因此不能据此推断现实中的最终产物。

## 定量状态

- 每个容器分别保存 `contents: { id, phase, moles }[]`。`s / l / g / aq` 区分固相、液相、气相与溶液中的溶质。同一物质在不同相中独立计量。
- 溶液加样：`n = c × V / 1000`，V 单位 mL，c 单位 mol/L；同时加入水作为显式溶剂。假设密度 1 g/mL、忽略溶质体积与混合收缩。
- 固体加样：`n = m / M`；气体：`PV = nRT`，1 atm、22 °C；水的摩尔体积近似 18.015 mL/mol。
- 反应进度 `ξ` 为计量方程式进行的 mol 数；所有反应物按系数消耗，所有产物按系数生成。`Δξ` 不超过任何反应物允许的最大值。
- 催化剂单独检查，不出现在净消耗项中。MnO₂ 的存在使过氧化氢的教学速率乘以 65；实际速率也与催化剂表面积等有关，未建模。
- 速率参数用于便于观察的课堂动画，以浓度、温度、催化剂修正；不是实验测量值。反应进度显示为已消耗进度 / 截至当前加样的可反应进度；再次加样后百分比可能降低。
- 空气的供氧作为每个开放容器独立的 0.1 mol O₂ 储量；消耗进入 `airUsed`。空气不限量/流体动力学未模拟。
- 逸出气体、集气瓶容量溢出的气体和蒸发水进入 `released` 环境账本。因此测试能验证包含环境交换后的元素守恒。手动加样、清空、移除仪器是外部物质输入/处置操作，不能与闭合系统混淆。

## 环境与热过程

温度以一阶传热模型接近目标温度。需要先开启酒精灯；含水容器温度近似限制为 100 °C，干燥固体可升至更高温度。中和反应按教学反应热与水热容估计升温。热容忽略容器与固体。点燃状态独立控制镁燃烧；没有氧气时不会凭空燃烧。

**不模拟压力、玻璃热应力、相变平衡、导管倒吸、沸点随压力变化、爆炸与真实火灾。密闭加热在本模型中不能用来判断安全性。**

## 气体收集

发生容器必须有橡胶塞并连接集气瓶，气体才会沿导管转移。无密封时气体逸出；无导管的密闭容器保留气体。集气瓶按当前温度、1 atm 显示理想气体等效体积，最多显示其标称容积，超出的部分进入环境账本。这里使用理想化排空气集气；气体密度分层、溶解度、排水集气与装置气密性未模拟。水槽目前为液体容器，不能等同于完整排水装置。

## 酸碱与指示剂

pH 是 25 °C、理想稀溶液近似：强酸强碱按剩余当量，乙酸按 Ka≈1.8×10⁻⁵。忽略活度、盐类水解、缓冲体系、碳酸平衡、硫酸第二步有限解离、指示剂本身引入的酸碱性和温度对 Kw 的影响。

酚酞按 pH 8.2–10 的区间连续插值至粉红色；极强碱褪色未建模。石蕊为复杂混合物，数据库化学式仅作为代表发色团的教学等效式，不能视为其真实单一分子式。指示剂不被净消耗。

## 物理分离

- 目前只对 NaCl 实现定量溶解、饱和与结晶。溶解度约 `6.1 + 0.0015 × max(T−20, 0)` mol/L，属于便于教学的近似；其他物质的通用溶解度未实现。
- 搅拌加快溶解速度。超过溶解度时将 `NaCl:aq` 转为 `NaCl:s`，反向过程同样守恒。
- 近沸点时，开启加热且未密封的容器可以蒸发水。蒸发皿 0.8 mL/s、其他容器 0.25 mL/s，均为压缩时间参数。水减少使溶液达到饱和并析晶。
- 过滤转移全部水与溶解物，保留不溶固体；不能移除已溶解的离子。漏斗视为已安装滤纸。
- 倒液默认转移 50% 的液体和溶质；搅拌状态视为悬浮液，连同 50% 固体转移。非搅拌状态保留沉降固体。移开源容器橡胶塞与导管后进行转移。

## 时间与动画

固定 0.1 s 模拟步长，与屏幕刷新率分离。0.25×–4× 只改变每秒运行的模拟步数。暂停停止求解；快照记录温度、物质数量、反应进度、环境账本、连接与仪器位置。最近 6001 帧（约 10 分钟）作为内存环形历史；回放读取真实快照，修改历史状态后创建新的历史分支，舍弃原分支未来状态。

Canvas 气泡按气体生成进度增量产生，速率降低后减少，剩余气泡继续上升；沉淀颗粒按实际固相数量出现，形成后聚集沉降。颜色由溶质浓度和指示剂 pH 派生。CSS 火焰由加热/燃烧状态控制；不使用 GIF、视频或预渲染动画代替反应。

微观模型覆盖所有 14 条规则，并独立测试原子与电荷守恒。强电解质显示净离子模型与旁观离子说明，固体用式量/晶格示意。原子重排、键的断开/形成仅为示意，不代表真实分子几何、势能面、晶体结构或反应机理。

## 扩展与校验

新增物质至 `src/data/substances.ts`；新增反应至 `src/data/reactions.ts`；添加净微观模型至 `src/chemistry/micro.ts`。扩展教学配方至 `src/data/experiments.ts`。反应规则必须使用数据库中已有的 id，正确设置相态、整数计量系数与条件。

`npm test` 自动校验数据库唯一性、所有规则的元素与质量配平、所有微观模型的原子与电荷守恒、反应求解全过程的物质守恒，以及限量、催化、浓度、传热门槛和分离过程。
