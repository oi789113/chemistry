# 操作与扩展

## 自由实验：蓝色沉淀

1. 点击“自由实验”，已有空烧杯。
2. 搜索 `CuSO4`，添加溶液态 20 mL、0.25 mol/L，共 5 mmol。
3. 搜索 `NaOH`，添加溶液态 20 mL、0.5 mol/L，共 10 mmol。
4. 播放，观察 Cu(OH)₂ 生成、聚集、下沉与上清液变浅。
5. 放置玻璃棒，点击搅拌；切换微观模式和离子方程式。
6. 暂停，拖动时间轴比较前后；在“物质变化”查看当前存量，实验记录可导出。

## 架构

`chemistry/engine.ts` 不依赖 DOM 或 React。`stepSimulation` 接收快照并返回新快照，不修改输入。UI 只通过操作入口添加试剂或改变条件，不能自行创建反应产物。教学与自由实验共用规则引擎。

SVG 与 Canvas 使用 `geometry.ts` 的同一器皿路径，保证液体被裁剪到玻璃内部。Canvas 用固定种子生成位置，时间取模拟状态，同一快照得到相同化学动画画面。CSS 只承担火焰形变和一次添加 / 倾倒反馈；暂停时持续火焰形变也停止。

Zustand 的 `history / cursor / playbackTime` 管理快照回放。修改过去截断未来；直接播放历史不重算操作。教学完成标记也保存在快照中。单次日志最多 200 条。

## 添加物质

在 `substances.ts` 增加结构化资料：真实化学式、默认物态、分类、固体 / 溶液颜色、性质、条件、安全信息、规则引用。元素计数与摩尔质量自动解析。新增元素需在 `formula.ts` 补充可靠的原子质量。

`soluble` 允许直接选择溶液态，不代表完整溶解平衡。扩展定量溶解时，应提供溶解度依据、温度范围和对应测试，不用无限溶解度冒充。

## 添加规则与实验

在 `reactions.ts` 增加明确的计量系数、物态、条件、旁观物质允许列表与模型限制。催化剂独立声明，不放入被消耗的反应物。填写方程式、原理、现象、类型，需要时填写离子方程式。所有方程式必须通过元素和摩尔质量配平测试。

为新规则测试限制反应物、条件不满足、未知副反应组合、物态和守恒；视觉效果读取生成量、速率、进度。新教学配方放入 `lessons.ts`，步骤由 `store/lab.ts` 执行，不能跳过引擎直接设置完成进度。

仪器在 `instruments.ts` 定义能力、容量与限制，在 `Glassware.tsx / geometry.ts` 定义 SVG / Canvas 几何。新工具必须有相应操作，不能只加图标。

## 开发与后续部署

使用 `npm ci` 安装锁定依赖，`npm run format` 格式化。变更后运行 `npm run check`、`npm run build` 和相关浏览器测试。构建输出 `dist/` 可用于后续静态托管；当前不创建托管项目、不部署、不配置域名。无运行时密钥、后端或数据库环境变量。
