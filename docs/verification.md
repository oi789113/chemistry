2026-11-01 本地结果：33 项 Vitest 测试、12 项 Chromium 操作测试全部通过；TypeScript 严格检查、生产构建与格式检查通过。

## 单元与集成

`npm test`：33 项测试，涵盖数据库完整性、18 条方程式的元素和摩尔质量配平、限制反应物、不产生负值、稀释与催化剂负载、催化剂不消耗、理论产量一致、温度阈值、稀硫酸浓度边界、未知混合体系、气体容量与去向、装塞保留气体、开放供氧、pH 与早期温升、溶解 / 过滤 / 蒸发 / 结晶守恒、时间回放和十个教学实验的完整操作模型。

## 浏览器操作

`npm run test:e2e` 使用 Playwright 检查：

1. 首屏、物品卡片尺寸、SVG / Canvas、无页面异常、帮助关闭。
2. 化学式搜索、用量 / 浓度、未知组合提示。
3. 仪器拖入、指针拖动、键盘移动。
4. H₂O₂ 连接、催化、产物、暂停画面冻结、回到反应前与微观模式。
5. Cu(OH)₂ 沉淀名称、离子方程式与粒子模式。
6. 滴管选择溶液、0.05 mL、pH 与一次操作动画。
7. 高锰酸钾达到温度条件后制氧、火焰与熄灯。
8. 溶解、过滤至蒸发皿和析晶。
9. 定量倾倒、接收体积与选择状态。
10. 十个实验入口、实验记录 JSON 下载。
11. 排水集气的清水转移、水位与气体体积对应。
12. 手机无横向页面溢出、搜索、选择实验、播放控件。

失败时保留截图、trace 与页面结构，GitHub Actions 上传失败产物。文档截图只用于视觉检查，不是实验动画资源。
